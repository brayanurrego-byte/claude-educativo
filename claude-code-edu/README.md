# Claude Code — Web Educativa

Sitio educativo sobre Claude Code construido con React + Vite, listo para desplegar en Vercel.

## 🚀 Deploy en Vercel

1. Sube el proyecto a GitHub
2. Conecta el repo en [vercel.com](https://vercel.com)
3. Vercel detecta Vite automáticamente — clic en **Deploy**

No requiere variables de entorno (sitio estático).

## 🛠️ Desarrollo local

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```
